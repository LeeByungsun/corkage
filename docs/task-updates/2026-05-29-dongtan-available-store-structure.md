# Task Update - 2026-05-29

## 작업명

`/store` 동탄구 중심 구조 + 콜키지 가능 매장만 노출 + 주소 표시 보정

## 배경

지역을 서울/경기/시 단위 트리로 넓히기보다, 현재 DB 범위에 맞춰 동탄구를 먼저 완전히 정리하기로 했다.
또한 목록은 다시 `콜키지 가능` 매장만 보여주는 방향으로 바꿨다.

## 이번에 한 일

- `/store` 첫 화면을 `경기 화성시 동탄구` 기준으로 고정했다.
- 지역 선택 문구를 `동탄구 어느 동에서 찾으세요?`로 바꿨다.
- 지역 select를 `경기 화성시 동탄구` optgroup 아래 동 목록으로 보여준다.
- 선택 지역 결과는 `available` 매장만 보여준다.
- `unknown`, `unavailable` 매장은 `/store` 목록에서 제외된다.
- `경기도 화성시 오산동`처럼 원본 district에 `동탄구`가 빠진 값은 화면/필터에서 `경기도 화성시 동탄구 오산동`으로 접는다.
- 카드와 상세 지도 주소는 도로명 주소가 `지산2길 5`처럼 일부만 있을 때 `경기도 화성시 동탄구 지산2길 5` 형태로 보정해 보여준다.

## 남은 리스크

- 실제 DB 값 자체는 아직 모두 정규화된 것이 아니다. 이번 작업은 화면/필터 레이어에서 동탄구 구조로 접는다.
- 도로명주소 API 승인키로 dry-run 후 `db:normalize:districts --apply`를 실행하면 DB 레벨에서도 더 깨끗하게 합칠 수 있다.
- 서울/경기/시군구 트리는 보류했다. 지금은 동탄구 MVP 구조가 우선이다.
