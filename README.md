# corkage

콜키지 가능한 식당을 지도 기반으로 탐색하는 웹 서비스 준비용 저장소입니다.

지금 단계의 목표는 개발 착수 전 아래 2가지를 먼저 확정하는 것입니다.

1. 네이버 지도 / 네이버 API로 MVP가 가능한지 검증
2. 어떤 에이전트와 스킬 조합으로 기획-검증-구현을 진행할지 정리

## 현재 단계

현재는 구현 단계가 아닙니다.

우선순위는 아래 순서입니다.

1. API 사용 가능 여부 확인
2. 데이터 수집 전략 결정
3. 제품 기획 정리
4. 화면/플로우 설계
5. 그 다음에만 실제 개발 시작

## 현재 판단

- 네이버 지도 표시 자체는 가능성이 높습니다.
- 주소/좌표 변환도 가능합니다.
- 지역 검색도 가능합니다.
- 하지만 `콜키지 가능` 여부를 네이버 API만으로 바로 얻기는 어렵습니다.
- 따라서 MVP는 `지도 + 식당 후보 검색 + 수동/반수동 콜키지 데이터 축적` 구조가 가장 현실적입니다.
